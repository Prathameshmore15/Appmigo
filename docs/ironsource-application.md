## Steps to Apply

### Step 1: Create ironSource Account
1. Go to https://www.is.com/
2. Click "Sign Up" or "Get Started"
3. Select "Publisher" account type
4. Fill in your details

### Step 2: Get Your Publisher ID
1. Log into ironSource dashboard
2. Go to **Account** → **API**
3. Find your **Publisher ID**
4. Copy it (you'll need it for app-ads.txt)

### Step 3: Add Your Apps
1. Go to **Monetize** → **Mediation** → **App Settings**
2. Click "Add App"
3. Enter package name: `com.appmigo.speedmemorychallenge`
4. Select "Google Play" as the store
5. Set category: Puzzle

### Step 4: Update app-ads.txt
After getting your Publisher ID, update `src/data/app-ads.txt`:

```
# app-ads.txt - https://iabtechlab.com/app-ads-txt/
# Owner: Prathamesh More (Appmigo)
# Website: https://appmigo.vercel.app

# ironSource
ironsrc.com, YOUR_PUBLISHER_ID, DIRECT

# ironSource authorized resellers
blueseasx.com, 203625, RESELLER
```

**Replace `YOUR_PUBLISHER_ID` with your actual ironSource Publisher ID.**

### Step 5: Submit for Approval
1. Complete all app details
2. Upload screenshots
3. Submit for review
